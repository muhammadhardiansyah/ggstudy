🗺️ Peta Harta Karun Piksel

Mengenal List 2 Dimensi (Grid)

Misi Persiapan: "Computer Vision"

👁️ Bagaimana Komputer Melihat Gambar?

Tahukah kamu? Komputer tidak punya mata! Saat komputer melihat sebuah gambar (atau mendeteksi wajah), mereka sebenarnya sedang melihat angka-angka di dalam kotak-kotak kecil yang disebut Piksel.

Kotak-kotak ini tersusun rapi seperti papan catur. Ada Baris (Menurun/Y) dan Kolom (Mendatar/X).

Di Python, kita bisa membuat gambar piksel ini menggunakan List 2 Dimensi, yaitu List yang ada di dalam List!

📦 Teori: Membuat Grid dengan List

Mari kita buat peta berukuran 3x3. Angka 0 adalah tanah kosong, dan angka 1 adalah harta karun!

peta = [
  [0, 0, 0], # Ini Baris ke-0 (Y=0)
  [0, 1, 0], # Ini Baris ke-1 (Y=1) -> Harta ada di tengah!
  [0, 0, 0]  # Ini Baris ke-2 (Y=2)
]

Cara Mencari Koordinat: Di Python, kita memanggil Barisnya (Y) dulu, baru Kolomnya (X). Contoh: peta[Y][X].

🎯 Latihan Membaca Peta

Perhatikan tabel Peta Piksel di bawah ini:

X=0 X=1 X=2
Y=0 0 0 0
Y=1 0 1 0
Y=2 0 0 0

Untuk mengambil angka 1 (Harta Karun), koordinatnya adalah Baris Y ke-1 dan Kolom X ke-1. Cara menulis kodenya: peta[1][1].

🧩 Project Rumpang 1: Meminta Koordinat

Misi: Kita akan meminta pemain untuk menebak lokasi harta karun! Lengkapi tipe data int untuk memastikan inputnya berupa angka.

# Peta Harta Karun
peta = [
    [0, 0, 0],
    [0, 1, 0],
    [0, 0, 0]
]

print("Tebak lokasi Harta Karun (Pilih angka 0, 1, atau 2)")

tebak_x = ____(input("Masukkan posisi X (Mendatar): "))

🧩 Project Rumpang 2: Cek Isi Piksel

Misi: Gunakan logika If/Else. Ingat, saat membaca 2D List, kita tulis Y (Baris) dulu, baru X (Kolom)!

# Mengecek isi peta berdasarkan tebakan pemain
isi_kotak = peta[____][____]

# Jika isi kotak adalah 1 (Harta Karun)
if isi_kotak ____ 1:
    print("SELAMAT! Kamu menemukan Harta Karun!")
else:
    print("ZONK! Kamu hanya menggali tanah kosong.")

Petunjuk: Isi kurung siku dengan nama variabel tebak_y dan tebak_x. Gunakan tanda == untuk perbandingan!

🚀 Kode Lengkap: Radar Harta Karun

Salin kode ini. Coba jalankan dan tebak koordinat X=1 dan Y=1, lalu coba juga dengan angka lain!

peta = [
    [0, 0, 0],
    [0, 1, 0],
    [0, 0, 0]
]

print("=== RADAR HARTA KARUN ===")
print("Peta berukuran 3x3. Masukkan angka 0, 1, atau 2")

tebak_x = int(input("Koordinat X (Mendatar): "))
tebak_y = int(input("Koordinat Y (Menurun): "))

# Y ditulis duluan karena Y adalah Baris, X adalah Kolom
isi_kotak = peta[tebak_y][tebak_x]

print("-------------------------")
print("Menggali di koordinat X:", tebak_x, "Y:", tebak_y)

if isi_kotak == 1:
    print("💰 SELAMAT! HARTA KARUN DITEMUKAN!")
else:
    print("🍂 Zonk... Hanya tanah kosong.")
