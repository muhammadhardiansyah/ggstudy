🛡️ Sistem Kasir Anti-Rugi

Logika Percabangan (If, Elif, Else)

Tantangan Coding: Level Boss

🚨 Masalah Kritis di Kantin

Program kasir yang kita buat sebelumnya punya kelemahan besar!

Coba bayangkan: Total tagihan Rp 30.000, tapi pembeli hanya membayar Rp 10.000.

Apa yang terjadi jika program tetap menjalankan kembalian = uang - tagihan?

Hasilnya: Kembalian = -20.000 (Minus!)
Kantin akan bangkrut karena komputer tidak bisa menolak uang yang kurang! Kita butuh program yang bisa mengambil keputusan.

🚦 Lampu Lalu Lintas Pemrograman

Di Python, kita bisa mengajari komputer mengambil keputusan menggunakan 3 kata ajaib:

  • if (JIKA): Kondisi pertama. "Jika uangnya kurang, tolak!"
  • elif (ATAU JIKA): Kondisi kedua. "Atau jika uangnya pas, bilang terima kasih!"
  • else (SELAIN ITU): Jika semua kondisi di atas tidak cocok. "Selain itu (berarti uangnya lebih), hitung kembalian."

🧩 Latihan 1: Kasir Cerdas

Misi: Lengkapi logika dan simbol perbandingan (<, >, atau ==).

Ingat: < artinya Lebih Kecil, == artinya Sama Dengan.

uang_pembeli = int(input("Uang: "))
tagihan = 30000

# Kondisi 1: Uang lebih KECIL dari tagihan
if uang_pembeli ____ tagihan:
    print("Maaf, uang Anda kurang!")

# Kondisi 2: Uang SAMA DENGAN tagihan
____ uang_pembeli ____ tagihan:
    print("Terima kasih, uangnya pas!")

# Kondisi 3: Uang LEBIH (Sisa kemungkinan)
____:
    kembalian = uang_pembeli - tagihan
    print("Kembalian:", kembalian)

🧩 Latihan 2: Sistem Diskon 10%

Misi Ekstra: Berikan diskon 10% HANYA JIKA belanjanya LEBIH DARI 50.000!

Lengkapi operator > dan matematika diskon di bawah ini.

tagihan = int(input("Total Belanja: "))

# Cek apakah tagihan LEBIH BESAR dari 50.000
if tagihan ____ 50000:
    print("Hore! Dapat diskon 10%")
    
    # Hitung diskon: (tagihan dikali 10) dibagi 100
    potongan = (tagihan * ____) / ____
    
    # Kurangi tagihan awal dengan potongan diskon
    total_akhir = tagihan - ____
    
    print("Cukup bayar:", total_akhir)
else:
    print("Tidak ada diskon. Bayar:", tagihan)

🚀 Kode Bos: Kasir Anti-Rugi & Promo

Gabungan semuanya! Cobalah masukkan belanja Rp 60.000 (dapat diskon), lalu bayar dengan uang Rp 10.000 (uang ditolak!).

print("=== KANTIN PINTAR ===")
tagihan = int(input("Berapa total tagihan? Rp "))

# Sistem Diskon
if tagihan > 50000:
    potongan = (tagihan * 10) / 100
    tagihan = tagihan - potongan
    print("Dapat Diskon 10%! Tagihan baru: Rp", tagihan)

# Sistem Anti-Rugi (Pembayaran)
uang = int(input("Masukkan uang pembayaran: Rp "))

if uang < tagihan:
    kurang = tagihan - uang
    print("TRANSAKSI GAGAL! Uang kurang Rp", kurang)
elif uang == tagihan:
    print("Uang pas! Terima kasih.")
else:
    kembali = uang - tagihan
    print("Transaksi sukses! Kembalian: Rp", kembali)
