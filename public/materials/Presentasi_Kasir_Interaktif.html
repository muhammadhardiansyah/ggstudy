🗣️ Sistem Kasir Interaktif

Menggabungkan Fungsi (def) dengan Input User

Tantangan Coding: Level Lanjut (Advanced)

🛒 Masalah di Kantin Sebenarnya

Di dunia nyata, program kasir tidak mungkin sudah tahu harga dan jumlah pesanan sejak awal! Kasir harus mengetikkan harga dan jumlahnya saat ada pembeli datang.

Karena itu, kita akan meningkatkan program kita menggunakan perintah input().

Tantangan Baru: Nilai yang diketik melalui input() selalu dianggap sebagai Teks (String) oleh Python. Kita harus mengubahnya menjadi Angka (Integer) agar bisa dihitung!

🛡️ Senjata Baru: Konversi int()

Jika kita mengetik angka 10 di input(), Python melihatnya sebagai huruf "10", bukan angka sepuluh.

Jika huruf "10" dikali 3, hasilnya error atau menjadi "101010"! 😱

Solusi: Bungkus perintah input() dengan int(). Ini akan "memaksa" teks berubah menjadi angka utuh.

# Contoh yang BENAR:
jumlah = int(input("Beli berapa? "))

🧩 Latihan 1: Meminta Data dari Kasir

Misi: Lengkapi kode rumpang ____ di bawah agar komputer bisa bertanya kepada kasir, lalu mengubah jawabannya menjadi angka.

# Fungsi perhitungannya sama seperti sebelumnya
def hitung_total(harga, jumlah):
    return harga * jumlah

# Meminta kasir mengetik harga & jumlah
harga_pesanan = ____(____("Berapa harga 1 porsi? Rp "))
jumlah_beli = ____(____("Beli berapa porsi? "))

# Memasukkan jawaban kasir ke dalam fungsi
tagihan = hitung_total(harga_pesanan, jumlah_beli)
print("Total Tagihan: Rp", tagihan)

Petunjuk: Gunakan senjata baru kita int() dan perintah input() secara berurutan!

🧩 Latihan 2: Membayar dan Kembalian

Misi: Setelah tagihan muncul, kasir harus bertanya berapa uang yang diserahkan oleh pembeli.

def hitung_kembalian(uang, total):
    return uang - total

# Bertanya uang yang dibayarkan
uang_pembeli = int(____("Masukkan uang pembayaran: Rp "))

# Menghitung sisa kembalian (tagihan diambil dari kode sebelumnya)
kembalian = hitung_kembalian(____, tagihan)
print("Kembalian Anda: Rp", kembalian)

🚀 Kode Lengkap Program Kasir

Ini adalah program kasir sungguhan! Salin dan jalankan kodenya. Kamu bebas mengetik harga, jumlah, dan uang bayar sesukamu di terminal komputer!

def hitung_total(harga, jumlah):
    return harga * jumlah

def hitung_kembalian(uang, total):
    return uang - total

print("=== WARUNG KODING OTOMATIS ===")

# Tahap 1: Input Pemesanan
harga_pesanan = int(input("Berapa harga 1 porsi? Rp "))
jumlah_beli = int(input("Beli berapa porsi? "))

total_tagihan = hitung_total(harga_pesanan, jumlah_beli)
print(">> Total Tagihan: Rp", total_tagihan)
print("------------------------------")

# Tahap 2: Pembayaran
uang_pembeli = int(input("Uang yang dibayarkan: Rp "))
kembalian = hitung_kembalian(uang_pembeli, total_tagihan)

print(">> Kembalian: Rp", kembalian)
print("=== TERIMA KASIH ===")
