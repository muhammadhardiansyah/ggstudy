🔍 Misi Detektif Kita

Halo Detektif Cilik! Misi kita hari ini adalah mengukur usia seseorang dengan sangat akurat.

Kita tidak hanya mencari tahu umurnya dalam bentuk Tahun, tapi kita akan mencari tahu hingga sedetail Hari!

Untuk itu, kita butuh Senjata Matematika Baru!

⚙️ Senjata Rahasia: // dan %

Di Python, ada dua simbol ajaib yang akan sangat membantu kita:

  • // (Pembagian Bulat): Membagi angka tanpa koma. Cocok untuk mencari jumlah Tahun.
    Contoh: 400 // 365 = 1 (Tahun)
  • % (Modulo / Sisa Bagi): Mencari sisa dari pembagian. Cocok untuk mencari sisa Harinya.
    Contoh: 400 % 365 = 35 (Hari)

⏳ Langkah 1: Total Hari di Bumi

Pertama, gunakan modul datetime untuk mencari total hari sejak kamu lahir.

import datetime

# Waktu hari ini
sekarang = datetime.datetime.now()

# Tanggal lahir (Tahun, Bulan, Hari) - Contoh Kelas 6 SD
tanggal_lahir = datetime.datetime(2014, 5, 15)

# Menghitung total hari
selisih = sekarang - tanggal_lahir
total_hari = selisih.days

print("Total kamu hidup:", total_hari, "Hari!")

📅 Langkah 2 & 3: Tahun dan Sisa Hari

Sekarang, ayo gunakan senjata rahasia kita pada variabel total_hari (karena 1 tahun = 365 hari).

# Langkah 2: Mencari Tahun dengan Pembagian Bulat (//)
umur_tahun = total_hari // 365

# Langkah 3: Mencari Sisa Hari dengan Modulo (%)
sisa_hari = total_hari % 365

print("Usiamu:", umur_tahun, "Tahun dan", sisa_hari, "Hari")

💻 Kode Lengkap Mesin Detektif

Salin kode ini, lalu ubah angka 2014, 5, 15 dengan tanggal lahirmu sendiri!

import datetime

print("=== MESIN DETEKTIF WAKTU ===")

sekarang = datetime.datetime.now()
tanggal_lahir = datetime.datetime(2014, 5, 15) # Ubah bagian ini!

total_hari = (sekarang - tanggal_lahir).days
umur_tahun = total_hari // 365
sisa_hari = total_hari % 365

print("- Total hari hidup :", total_hari, "Hari")
print("- Usia kamu sekarang:", umur_tahun, "Tahun,", sisa_hari, "Hari")
print("============================")
