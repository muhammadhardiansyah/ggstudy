🎮 Game Tebak Angka

Perulangan Tanpa Henti (While True)

Mode Arcade: Siap Bermain?

🔄 Mesin yang Tidak Pernah Berhenti

Di pelajaran sebelumnya, program kita hanya jalan satu kali lalu selesai. Tapi, sebuah game harus terus berjalan sampai kita menang atau kalah, kan?

Untuk membuat program terus mengulang, kita menggunakan mantra while True: (Selama kondisinya Benar, ulangi terus!).

Rem Darurat: Karena while True akan berputar selamanya, kita WAJIB menyiapkan tombol stop. Perintah untuk menghentikan putaran ini adalah break.

🎲 Library Baru: Random

Kita sudah kenal math dan datetime. Sekarang saatnya memanggil random!

Untuk membuat komputer memikirkan angka acak dari 1 sampai 100, kita menggunakan perintah:

import random

# Komputer memilih angka acak antara 1 dan 100
angka_rahasia = random.randint(1, 100)

🚀 Kode Lengkap: Game Tebak Angka

Gabungkan kodenya dan mainkan di komputermu! Bisakah kamu menebak angkanya dalam kurang dari 7 percobaan?

import random

jawaban = random.randint(1, 100)
print("=== GAME TEBAK ANGKA ===")
print("Aku menyimpan angka rahasia dari 1 - 100.")

while True:
    tebakan = int(input(">> Masukkan tebakanmu: "))
    
    if tebakan < jawaban:
        print("❌ Terlalu KECIL! Naikkan lagi.")
    elif tebakan > jawaban:
        print("❌ Terlalu BESAR! Turunkan lagi.")
    else:
        print("🎉 TEPAT SEKALI! Angkanya adalah", jawaban)
        break # Keluar dari game

print("Game Selesai. Terima kasih sudah bermain!")
